# Grid-Trap

## 项目简介
- 通过C++的winsock2 API实现服务端、Unity实现客户端
- 通过ai辅助项目实现
- 采用状态同步和TCP的方案，通过Length-Prefixed Framing解决了粘包/半包的问题
- 一款支持4人联机的回合制派对游戏，可以和朋友一起玩

## 游戏流程介绍
- 客户端输入name、ip、port连接服务器，4个人连接后开始在网格上放置陷阱
- 每个玩家放置3个陷阱，都放置好后进入行动阶段
- 每个玩家的行动阶段轮流进行，在行动阶段，该玩家可以选择“直接选一个格子”或“点击随机事件按钮”
- 只要玩家选中一个有陷阱的格子就会掉血，血量为0的出局，最后存活的玩家胜利
